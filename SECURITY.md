# Security Policy

Hire.AI is an early-stage project and is not yet accepted for production use. Security reports are welcome and should be handled privately.

## Supported versions

There is no supported production release or service-level commitment. The published `v0.1.0-alpha.1` release is an evaluation preview only; maintainers may publish security fixes for the current `main` branch and preview release, but no response or remediation time is guaranteed. Do not use the preview to process real candidate data without completing the production acceptance requirements.

## Report a vulnerability

Use **Report a vulnerability** on the repository's GitHub **Security** tab. Private vulnerability reporting is enabled for this repository; this opens GitHub's private vulnerability reporting form and keeps details out of public issues and discussions. Include the affected commit or release, impact, reproduction steps, and a safe proof of concept where useful. Do not include real user data, credentials, or secrets in a report.

If private reporting is unavailable, open a public issue with only the title **Request private security contact**. Do not include vulnerability details, exploit code, affected user data, or credentials. Maintainers will provide a private reporting route.

## Scope and response

Reports involving authentication, authorization, candidate data, resumes, connector tokens, application actions, payments, privacy erasure, dependency vulnerabilities, or deployment configuration are in scope. Please allow maintainers time to investigate and coordinate a fix before public disclosure. Acknowledgement, severity assessment, remediation, and disclosure timing depend on impact and maintainer availability; no response-time or remediation-time guarantee is currently offered.

The project has no supported production release or service-level commitment yet. Security fixes and advisories will be published through the repository when appropriate. See [docs/SECURITY.md](docs/SECURITY.md) for the implemented controls and outstanding acceptance work.
